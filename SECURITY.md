# Security Policy

## Supported Versions

FrogUI follows semantic versioning. Critical security patches are backported to the latest minor release of the current major version.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in FrogUI, please **do not open a public GitHub issue**.

Instead, send a detailed report via email to:
**eswarchinthakayala85@gmail.com**

Please include:
* Component or module affected (`frogui-foundation`, `frogui-components`, `frogui-registry`, `app`)
* A clear description of the vulnerability and potential attack vectors
* Step-by-step reproduction instructions or a minimal proof of concept
* Any proposed mitigations or fixes

### Vulnerability Response SLA
* **Initial Acknowledgment**: Within 48 hours
* **Assessment & Timeline**: Within 5 business days
* **Public Disclosure**: Coordinated after fix verification and patch release
